## 三天上手指南

### Day 1（30 分鐘）— 讀

**只讀這三章：**
- 戰略指南 第一章（心智重設）
- 戰略指南 第二章（定位戰場）
- 戰略指南 第四章（90 天執行藍圖）

讀完後，做一件事：
> 寫下你的「定位陳述」黃金公式（戰略指南第 2.4 節）

### Day 2（60 分鐘）— 算

**打開財務模型：**
1. 雙擊 `04-Financial-Model.xlsx`
2. 到 **Assumptions** 分頁
3. 改藍色/黃色格子的數字（你的真實情況）
4. 看 **Monthly_Projection** 跟 **KPI_Dashboard** 結果
5. 做一件事：
   > 算出你的「損益平衡所需月毛收入」與「現金跑道」

### Day 3（60 分鐘）— 用

**打開 Dashboard：**
1. 雙擊 `05-KPI-Dashboard.html`（瀏覽器會打開）
2. 輸入本月實際數字
3. 看健康讀數
4. 點擊「儲存」（資料只在你的瀏覽器，不上傳）

**用模板：**
1. 把 `weekly-os.md` 內容複製到你的 Notion / 紙本
2. 每週一早上花 30 分鐘填寫
3. 週日晚上花 30 分鐘檢視

**用 Prompts：**
1. 打開 `03-Prompts-Library.md`
2. 找一個跟你目前最相關的 Prompt
3. 複製貼到 ChatGPT / Claude / Gemini，把括號內容換成你的情境

## 使用優先順序（如果只能用三件）

**如果你只能用三個工具，請依序：**

1. **戰略指南第二章（定位戰場）**  
   → 先把「我幫誰、解決什麼、得到什麼結果」想清楚。  
   → 不想清楚，後面所有工具都是浪費時間。

2. **客戶管線管理表**  
   → 強迫自己永遠維持「5 個階段同時推進」。  
   → 這是 Solo 不裸奔的關鍵。

3. **財務模型 + Dashboard**  
   → 強迫自己每週看數字，不靠感覺經營。

## 常見錯誤

### ❌ 錯誤 1：只讀不做

戰略指南讀完很爽，但沒填模板、沒跑數字、沒寫定位陳述——  
那只是讀了一本書，你的人生不會改變。

**修正：** 每個模組都要產出一個「實體輸出」（一份檔案、一個決定、一個行動）。

### ❌ 錯誤 2：什麼都想完美再開始

「等我把財務模型搞懂再開始談客戶」——  
財務模型可以邊做邊改，但客戶等不了你。

**修正：** Day 8 就開始發訪談邀請。財務模型可以邊跑邊優化。

### ❌ 錯誤 3：把工具當成解藥

工具不會幫你做決定，只會幫你看清楚。  
看清楚之後，決定還是你的。

**修正：** 每個工具用完問自己「我接下來做什麼」，不是「我下一個工具是什麼」。
